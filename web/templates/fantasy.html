How a score is built

Every component, what it's worth, and what the qualifying players average. A game is worth +3 to start and each death eats 0.2 of it, so fifteen deaths cancels it out. Longer games earn more of everything, so a score is corrected for the length of the games it came from — the average is {{ duration_mean }} minutes, and a player whose games ran longer gives some back.
