Season setup

Points a division at a season and loads everything it needs: week boundaries, the drafted rosters, and team names and logos. A season is its Dota league id, so several divisions can share one — run this once for each. Running it again on the same league tops up whatever didn't load the first time and leaves matches and weeks alone.

Just record a season without rolling a division onto it

The URL name appears in season links, e.g. /season/20056/na. Region and mode decide which of a league's games count as this division's — a league is filtered by server cluster and game mode. Which season a division is on is set by Season setup above.
